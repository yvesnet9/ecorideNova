# 🌿 EcoRideNova

**EcoRideNova** est une application web de covoiturage écologique développée dans le cadre du **Titre Professionnel Développeur Web et Web Mobile**.  
Elle permet de mettre en relation des conducteurs et des passagers souhaitant partager leurs trajets, en privilégiant les véhicules électriques.

---

## 🚀 Objectifs du projet
- Réduire l’impact environnemental des déplacements
- Offrir une plateforme intuitive et sécurisée
- Gérer les comptes utilisateurs (chauffeurs, passagers, employés, administrateurs)
- Mettre en œuvre un système de crédits pour la participation aux trajets

---

## 🧱 Stack technique
| Couche | Technologies |
|--------|---------------|
| Front-end | HTML5, CSS3 (Bootstrap), JavaScript |
| Back-end | PHP 8+ avec PDO |
| Base SQL | MySQL ou PostgreSQL |
| Base NoSQL | MongoDB |
| Déploiement | Vercel / Fly.io / Heroku / Azure |
